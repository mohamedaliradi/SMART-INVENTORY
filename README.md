# SMART INVENTORY – نظام الجرد الذكي

مستودع سورس كود مشروع **SMART INVENTORY**.

## حالة النسخة
الفرع `postgres-migration-phase-1` يحتوي على أساس أولي لمخطط PostgreSQL ومستند يوضح خطوات الترحيل. **التطبيق نفسه لم يُنقل بعد إلى PostgreSQL**؛ ملف `backend/app.py` ما زال يعتمد على SQLite، لذلك لا تعتبر هذه المرحلة نسخة تشغيل متعددة الأجهزة أو جاهزة للإنتاج.

## الاتجاه التقني المعتمد
- PostgreSQL قاعدة البيانات التشغيلية المركزية.
- CSV للتصدير والنسخ الاحتياطية القابلة للتنزيل من داخل التطبيق.
- GitHub لحفظ السورس كود وملفات الترحيل فقط.
- نشر التطبيق وقاعدة البيانات على بيئة تشغيل آمنة، مع HTTPS وإدارة أسرار خارج المستودع.

## ملفات المرحلة الحالية
- `backend/migrations/001_initial_postgresql.sql`: مسودة مخطط PostgreSQL.
- `backend/POSTGRESQL_MIGRATION_STATUS_AR.md`: ما تم وما لم يتم وخطوات القبول.
- `backend/.env.example`: مثال إعداد اتصال مستقبلي دون بيانات اعتماد حقيقية.

## النسخة الحالية قبل إتمام الترحيل
التعليمات القديمة الخاصة بتشغيل Windows وSQLite لا تعني أن PostgreSQL أو الوصول عبر الإنترنت أصبحا جاهزين. لا تنشر بيانات فعلية ولا تضع قاعدة بيانات أو CSV حقيقية داخل المستودع.

## متطلبات ما قبل الإطلاق
يجب إكمال طبقة PostgreSQL، وترحيل البيانات، وتصدير CSV المحمي، والنسخ الاحتياطي والاستعادة، واختبارات الصلاحيات والتزامن والعمل Offline، ثم نشر التطبيق على HTTPS. راجع مستند حالة الترحيل داخل مجلد backend.
