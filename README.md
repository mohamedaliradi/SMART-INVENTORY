# SMART INVENTORY – نظام الجرد الذكي

مستودع سورس كود مشروع **SMART INVENTORY**.

## محتويات إصدار التجربة الحالي
ملف الإصدار المضغوط سيُضاف إلى مجلد `releases/` عند إرفاقه من بيئة رفع الملفات:
- تطبيق Python / FastAPI.
- واجهة عربية RTL قابلة للتثبيت كتطبيق ويب PWA.
- ملفات إعداد وتشغيل Windows.
- أداة إعادة تعيين كلمة مرور المدير.
- أداة نسخ احتياطي.
- اختبارات API أساسية.

## التشغيل على Windows
1. نزّل وفك ضغط حزمة الإصدار.
2. افتح مجلد `backend`.
3. تأكد من تثبيت Python 3.11 أو أحدث وإضافته إلى PATH.
4. شغّل `setup.bat` وانتظر تثبيت المكتبات وإعداد حساب المدير.
5. شغّل `start.bat` واترك نافذة الخادم مفتوحة.
6. افتح `http://127.0.0.1:8000`.

## تشغيل الاختبارات
من داخل مجلد `backend`:
```bash
python -m pytest -q
```

## تنبيهات مهمة قبل الاستخدام الفعلي
- هذا إصدار مرشح للتجربة والتطوير، وليس إصدار إنتاج نهائي معتمد.
- قاعدة البيانات في هذا الإصدار SQLite؛ لم يُنفذ ترحيل PostgreSQL أو اختبار حمل واقعي لأكثر من 30 موظفاً متزامناً.
- وضع Offline محدود بالتخزين المحلي للعمليات والأصناف التي تم تحميلها مسبقاً، والمزامنة عند عودة الاتصال وفتح التطبيق.
- لا تمسح بيانات المتصفح قبل التأكد من اكتمال المزامنة.
- لا يوجد إعداد جاهز للوصول الآمن من خارج الشركة. لا تفتح المنفذ 8000 مباشرة على الإنترنت.
- يجب أن يظل جهاز الخادم يعمل ومتصلًا بالشبكة.
- خذ نسخاً احتياطية دورية واحتفظ بها خارج جهاز الخادم.

## حماية البيانات
لا ترفع إلى هذا المستودع قواعد بيانات فعلية أو ملفات `admin_setup.json` أو `.env` أو كلمات مرور أو مفاتيح وصول أو نسخاً احتياطية تحتوي بيانات حقيقية. أضيف ملف `.gitignore` لاستبعاد هذه العناصر.

## الترخيص
لم يُضف ترخيص مفتوح المصدر. لا يُفترض السماح بإعادة الاستخدام أو التوزيع قبل تحديد ترخيص صريح من مالك المشروع.
