# SMART INVENTORY – نسخة GitHub + CSV التجريبية

هذه النسخة واجهة ثابتة (Static PWA) قابلة للنشر عبر GitHub Pages. لا تحتوي على خادم خلفي ولا قاعدة بيانات مشتركة.

## طريقة البيانات
- `data/catalog.csv` ملف أصناف ابتدائي للقراءة والتنزيل.
- سجلات الجرد الجديدة تحفظ في IndexedDB داخل متصفح الجهاز الحالي.
- يمكن تصدير السجلات إلى CSV واستيراد CSV يدوياً على جهاز آخر.
- لا تتم الكتابة إلى ملفات المستودع من المتصفح، ولا تتم مزامنة تلقائية بين الموظفين.

## النشر
فعّل GitHub Pages من إعدادات المستودع باختيار GitHub Actions كمصدر النشر. ملف workflow في `.github/workflows/deploy-csv-pages.yml` ينشر محتويات مجلد `docs`.

## حدود مهمة
1. GitHub Pages يقدم ملفات ثابتة فقط؛ لا يشغل FastAPI أو PostgreSQL.
2. ملف CSV داخل المستودع ليس قاعدة بيانات تشغيلية قابلة للتحديث المباشر من الزوار.
3. IndexedDB منفصل لكل متصفح/جهاز؛ مسح بيانات المتصفح قد يؤدي لفقد النسخة المحلية.
4. لا تضع كلمات مرور أو بيانات موظفين حساسة أو بيانات جرد سرية في CSV أو الملفات الثابتة.
5. هذه نسخة تجريبية لجرد محدود وتبادل ملفات CSV يدوياً، وليست بديلاً عن نظام مركزي متعدد المستخدمين.

## الاستخدام
افتح الرابط بعد تفعيل Pages، أدخل الفرع والموظف، سجل الأصناف، ثم صدّر CSV واحتفظ بنسخة احتياطية. لجمع نتائج عدة موظفين، يستورد المسؤول ملفاتهم إلى ملف تجميعي خارج التطبيق أو على جهاز واحد.
